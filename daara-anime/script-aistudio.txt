SCRIPT AI STUDIO : LE RÈGLEMENT DE LA DAARA EN IMAGES 3D
==========================================================

COMMENT FAIRE
1. Ouvrez aistudio.google.com et touchez « Chat ».
2. Dans le choix du modèle (en haut à droite), prenez un modèle d’IMAGES :
   « Nano Banana » / « Gemini … Flash Image » (le nom contient « Image »).
3. Restez dans la MÊME conversation du début à la fin : c’est ce qui garde
   les mêmes visages pour Fallou et Diarra.
4. Collez le MESSAGE 1, attendez l’image, puis le MESSAGE 2, et ainsi de suite.
5. Si une image ne va pas, écrivez : « Refais la même image, mais … ».
6. Téléchargez chaque image (bouton ↓), en les gardant dans l’ordre.
7. Dans CapCut : mettez les images dans l’ordre, ajoutez un zoom lent
   (« Animation » > « Zoom »), puis les voix du fichier zip (le nom de
   chaque voix est indiqué sous chaque message), et les sous-titres auto.

Si AI Studio refuse de créer des images, votre compte n’a pas de quota
gratuit pour ce modèle : utilisez alors l’application Gemini sur le
téléphone avec les mêmes messages.
